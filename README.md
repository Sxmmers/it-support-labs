# IT Support Labs

Hands-on IT support and systems administration labs focused on Windows administration, troubleshooting, networking, PowerShell, and remote system management.

This repository documents practical troubleshooting scenarios and administrative tasks performed in a virtualized lab environment.

---

## 🎯 Objectives

The goals of this lab are to develop practical experience with:

* Windows system administration
* IT troubleshooting methodology
* PowerShell
* Windows services and processes
* Users, groups, and permissions
* Network configuration and connectivity
* DNS and DHCP troubleshooting
* Remote administration
* System diagnostics
* Documentation and incident resolution

## 🧪 Troubleshooting Methodology

Each troubleshooting exercise follows a structured process:

```text
Identify the Problem
        ↓
Gather Information
        ↓
Form a Hypothesis
        ↓
Test the Hypothesis
        ↓
Identify the Root Cause
        ↓
Apply a Resolution
        ↓
Verify the Fix
        ↓
Document the Result
```

The goal is to develop a repeatable troubleshooting process rather than relying on trial and error.
